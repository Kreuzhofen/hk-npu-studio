\# Security Policy



\## Reporting a Vulnerability



If you discover a security vulnerability, please do not disclose it publicly before it has been reviewed.



Please open a private security report or contact the project maintainer with:



\- Description of the issue

\- Steps to reproduce

\- Potential impact

\- Suggested mitigation (if available)



Every report will be reviewed as quickly as possible.
