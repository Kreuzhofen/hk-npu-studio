# Architekturentscheidungen (Architecture Decision Records - ADRs)

In diesem Verzeichnis werden wesentliche Architekturentscheidungen dokumentiert. Jede Entscheidung erhält ein eigenes Dokument (ADR) im Markdown-Format.

## ADR-Struktur
Jedes ADR sollte folgendem Muster folgen:
* **Status:** Vorgeschlagen / Akzeptiert / Veraltet
* **Kontext:** Welches Problem wird gelöst? Welche Rahmenbedingungen gelten?
* **Entscheidung:** Wie wird das Problem gelöst?
* **Konsequenzen:** Welche Vor- und Nachteile ergeben sich durch die Entscheidung?
