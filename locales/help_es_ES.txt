HK NPU STUDIO – Ayuda paso a paso

1. ¿Qué es HK NPU STUDIO?
---------------------------------
HK NPU STUDIO crea imágenes a partir de descripciones de texto. El procesamiento se ejecuta localmente en su PC con Windows. Según el modelo, la aplicación utiliza la NPU Snapdragon o la CPU.

Un «modelo» es el archivo que ha aprendido a crear imágenes. El modelo debe estar instalado y activado antes de poder crear una imagen.

2. Requisitos
-------------
- Un PC Windows 11 ARM64 con Qualcomm Snapdragon.
- Espacio libre suficiente para el modelo elegido.
- Para modelos NPU: un runtime Qualcomm QNN funcional y controladores compatibles.
- Un paquete de modelo instalado por completo.
- Para una importación local: un archivo ZIP o SMP compatible.

La aplicación no descarga todos los modelos automáticamente. Si no hay una fuente oficial configurada, necesita un paquete local ya descargado.

3. Primer inicio
----------------
1. Inicie HK NPU STUDIO. En el primer inicio, una verificación de preparación en segundo plano analiza su entorno del sistema (Windows 11 ARM64, controladores NPU, Python).
2. Espere hasta que se cargue la vista principal.
3. Abra el «Gestor de modelos» en la navegación izquierda.
4. Busque el modelo deseado (se recomienda Stable Diffusion 1.5 QNN para comenzar).
5. Compruebe el estado: si el modelo aparece como «No instalado», siga las instrucciones de la sección 6.
6. Una vez que un modelo esté instalado, selecciónelo y haga clic en «Establecer como modelo activo».
7. Vaya a «Generación con IA» para crear su primera imagen.

4. Resumen de la interfaz
-------------------------
- «Inicio»: muestra el estado general.
- «Generación con IA»: aquí escribe el prompt e inicia una imagen.
- «Gestor de modelos»: aquí instala y activa modelos.
- «Galería»: muestra las imágenes guardadas.
- «Configuración»: contiene, entre otras opciones, el idioma y las carpetas de almacenamiento.

En «Generación con IA» encontrará:
- «SU INDICACIÓN» y «EXCLUIR (MENSAJE NEGATIVO)» para introducir texto.
- «Ajustes preestablecidos y plantillas» para ajustes guardados.
- «Phoenix Boost» para sugerencias locales de prompts.
- «Parámetros de generación» para resolución, pasos, CFG, semilla y otros valores.
- «ControlNet/Canny» para guiar la imagen con una referencia.
- «Historia» para prompts anteriores.
- «GENERAR IMAGEN →» para iniciar.

5. ¿Qué modelo debo elegir?
---------------------------
Stable Diffusion 1.5 (SD1.5)
- Una opción sencilla para empezar, con resolución nativa de 512 × 512.
- Phoenix ofrece variantes QNN y variantes opcionales QAI AppBuilder.

Stable Diffusion 2.1 (SD2.1)
- Una alternativa a SD1.5 con características visuales propias.
- Los paquetes QNN/QAI actuales usan 512 × 512.

Stable Diffusion 3.5 Medium QAI AppBuilder
- Es el modelo NPU más grande de esta lista.
- Phoenix utiliza una resolución fija de 1024 × 1024.
- Necesita un paquete local con cuatro contextos QAI, dos tokenizadores y archivos adicionales.

Stable Diffusion XL Base (SDXL)
- Se ejecuta mediante la CPU en la ruta actual de Phoenix.
- Utilice la resolución y los valores predeterminados que Phoenix muestre para el paquete instalado.

QNN y QAI en palabras sencillas
- La NPU es la parte del procesador Snapdragon que realiza cálculos de IA.
- QNN es el runtime de Qualcomm para esta NPU.
- QAI AppBuilder carga contextos de modelo preparados. Phoenix los ejecuta en un proceso de trabajo separado.
- No necesita configurar estos términos. Seleccione el modelo instalado correspondiente.

6. Paso a paso: instalar un modelo
----------------------------------
1. Abra «Gestor de modelos» a la izquierda.
2. Haga clic en el modelo deseado.
3. Compruebe el estado:
   - «No instalado»: los archivos de modelo necesarios no están disponibles localmente en su sistema.
   - «Instalado»: se encontró el paquete y está listo.
   - «Modelo activo»: este modelo está seleccionado actualmente para las generaciones.
4. Para un modelo marcado como «No instalado», haga clic en «Instalar».
5. En el diálogo de instalación, según el modelo, hay hasta tres opciones disponibles:
   - DIRECT / OFFICIAL_EXTERNAL: Descargar desde un sitio web o fuente oficial configurada (Hugging Face / enlace de Qualcomm). Nota: No hay descarga directa totalmente automatizada desde Qualcomm AI Hub; se le guiará a la página oficial de descarga correspondiente.
   - LOCAL_ONLY: Importar un paquete local que ya haya descargado manualmente.
   - Cancelar: Finaliza el proceso de instalación.
6. Para la importación local (LOCAL_ONLY): Seleccione el archivo ZIP o SMP correspondiente en el diálogo de archivos de Windows.
7. El instalador comprueba y descomprime el paquete (staging), realiza la verificación estática y mueve los archivos a su directorio de modelos.
8. Tras una importación correcta, seleccione de nuevo el modelo y haga clic en «Establecer como modelo activo».
9. Haga clic en el botón «Crear primera imagen» para ir directamente a la página de generación.

Nota sobre Hugging Face: Introducir un token de Hugging Face en la configuración es opcional. Solo se requiere un token para acceder a ciertos modelos protegidos por contraseña en Hugging Face; no existe un requisito general de registro o token.

Phoenix comprueba el ID del paquete, el manifiesto y los archivos. No cambie por su cuenta los nombres del contenido del modelo.

7. Paso a paso: crear la primera imagen
---------------------------------------
1. Active un modelo instalado en «Gestor de modelos».
2. Abra «Generación con IA» a la izquierda.
3. En «SU INDICACIÓN», escriba por ejemplo:
   a professional photograph of a red sports car on a mountain road, daylight, sharp focus
4. En «EXCLUIR (MENSAJE NEGATIVO)», escriba por ejemplo:
   blurry, distorted, low quality
5. Abra «Parámetros de generación».
6. Para el primer intento, mantenga los valores predeterminados mostrados para el modelo.
   - SD1.5/SD2.1: 512 × 512, normalmente 20 pasos y CFG 7,5.
   - SD3.5 Medium QAI: 1024 × 1024, 8 pasos y CFG 3,5.
   - SDXL: los valores del paquete que se muestran actualmente.
7. Use la semilla -1 para una imagen aleatoria o, por ejemplo, 12345 para un valor inicial repetible.
8. Cierre o aplique el diálogo de parámetros.
9. Haga clic en «GENERAR IMAGEN →».
10. Observe el estado y el progreso. No cierre la aplicación durante la generación.
11. Tras completarse, el estado muestra el tiempo total medido.
12. La imagen aparece en la vista previa y se guarda en la carpeta de salida. También puede encontrarla en «Galería».

La duración depende del modelo, los pasos, el escalado, el hardware y otros programas en ejecución.

8. Parámetros en palabras sencillas
------------------------------------
- Pasos: número de pasos de eliminación de ruido. Más pasos necesitan más tiempo. Más no siempre significa mejor.
- Escala CFG: intensidad con la que el modelo sigue el prompt. Para muchos modelos Stable Diffusion clásicos, entre 6 y 8 es un rango útil. Para SD3.5, empiece con el valor predeterminado mostrado.
- Semilla: número inicial del cálculo de la imagen. La misma semilla y los mismos ajustes ayudan a repetir un resultado. -1 elige una semilla aleatoria.
- Sampler: método de cálculo usado para formar la imagen.
- Scheduler: distribuye los pasos de eliminación de ruido durante el proceso.

Si Sampler o Scheduler están desactivados, están fijados para ese modelo o backend.

9. Presets
----------
Un preset guarda el prompt, el prompt negativo y los valores de generación, lo que permite cargarlos rápidamente.

Reglas al aplicar un preset:
- El modelo activo no se cambia al cargar un preset (el modelo seleccionado se conserva).
- Un estado activo de ControlNet y la imagen de referencia cargada se conservan.
- El prompt, el prompt negativo y los parámetros compatibles se aplican directamente.
- Los parámetros no compatibles con el modelo activo se ajustan automáticamente a los límites del modelo activo.
- El diálogo de selección de presets se puede abrir repetidamente sin errores.

Usar una plantilla existente:
1. En «Generación con IA», haga clic en «Ajustes preestablecidos y plantillas».
2. Seleccione una plantilla.
3. Haga clic en «Aplicar».

En la misma ventana puede «Renombrar» o «Eliminar» plantillas. Puede crear una plantilla nueva después de una vista previa de Phoenix Boost mediante «Guardar como plantilla».

10. Phoenix Boost
-----------------
Phoenix Boost es un asistente de IA puramente opcional para optimizar prompts.
- Cómo funciona: La función mejora el prompt introducido y sugiere parámetros coincidentes (pasos, CFG) y exclusiones. La ejecución se realiza localmente y sin conexión utilizando Ollama y el modelo Qwen (no se requiere nube).
- Importante: Phoenix Boost NO es necesario para la generación de imágenes normal. Es una ayuda de formulación y NO un aumento de velocidad que acelere el proceso de generación real.

Operación:
1. Escriba primero un prompt.
2. Haga clic en «Phoenix Boost».
3. Compare el original y la sugerencia.
4. Compruebe el prompt negativo, los pasos, CFG y la resolución.
5. Haga clic en «Aplicar» o «Cancelar».
6. Opcionalmente, seleccione «Guardar como plantilla».

11. RealESRGAN 2x – paso a paso
--------------------------------
RealESRGAN amplía la imagen terminada al doble de ancho y alto. El original se conserva. La ruta actual del plugin utiliza el backend QNN existente.

1. Abra «Parámetros de generación».
2. Active «Ampliar 2× con RealESRGAN después de generar».
3. Aplique los ajustes.
4. Haga clic en «GENERAR IMAGEN →».
5. Espere primero a la generación normal y después al escalado.
6. La carpeta de salida contiene el original y un archivo adicional con «_2x» en el nombre.

Si la opción está desactivada, el flujo de generación no cambia. El runtime QNN y el modelo RealESRGAN deben estar disponibles para el escalado.

12. ControlNet Canny – paso a paso
----------------------------------
ControlNet Canny copia los bordes de una imagen de referencia. Así puede guiar la forma general de la imagen nueva.

1. Abra «Gestor de modelos».
2. Instale «ControlNet Canny QNN» y establezca exactamente este modelo como modelo activo. Ya contiene la canalización base SD1.5 necesaria. No deje activo «Stable Diffusion 1.5 QNN» en su lugar; Phoenix utiliza un solo modelo activo cada vez.
3. Abra «Generación con IA».
4. Haga clic en «ControlNet/Canny» en la barra del prompt. Se abre una ventana propia; no es una pestaña.
5. Active además la casilla «ControlNet Canny» en la ventana. Esto habilita la guía Canny para el trabajo; no activa un segundo modelo base.
6. Haga clic en «Seleccionar imagen» o arrastre una imagen al área de referencia.
7. Compruebe «Imagen original» y «Vista previa Canny».
8. Si es necesario, ajuste «Canny Low Threshold», «Canny High Threshold» y «Fuerza de acondicionamiento». Para la primera prueba, mantenga los valores predeterminados.
9. Cierre la ventana. La imagen y los valores permanecen visibles en la interfaz.
10. Escriba el prompt y el prompt negativo.
11. Haga clic en «GENERAR IMAGEN →».

«Eliminar imagen» quita la imagen de referencia seleccionada del trabajo actual. ControlNet Canny usa 512 × 512 en Phoenix.

Nota: Si la casilla de verificación en el menú emergente está activa, el control de estructura se aplica de manera confiable al trabajo de generación.

13. Galería e Historia
-----------------------
- «Galería» muestra las imágenes generadas de la carpeta de salida. Seleccione una imagen para verla.
- «Historia» en «Generación con IA» muestra prompts anteriores y sus ajustes. Mediante la opción del menú «Historie leeren» / «Clear history», el historial se puede vaciar por completo después de confirmar un diálogo de seguridad. Importante: Los archivos de imagen generados en su disco NO se eliminan al borrar el historial.

Galería e Historia son independientes: Galería gestiona archivos de imagen físicos. Historia guarda sus entradas de generación.

14. Ubicaciones de almacenamiento y Configuración del sistema
-------------------------------------------------------------
Rutas predeterminadas en desarrollo:
- Imágenes: C:\SnapdragonAI\output
- Modelos: C:\SnapdragonAI\models
- Configuración e historial: C:\SnapdragonAI\data
- Logs: C:\SnapdragonAI\logs

Rutas predeterminadas en la versión instalada:
- Imágenes: %LOCALAPPDATA%\HK NPU STUDIO\output
- Modelos: %LOCALAPPDATA%\HK NPU STUDIO\models
- Configuración e historial: %LOCALAPPDATA%\HK NPU STUDIO\data
- Logs: %LOCALAPPDATA%\HK NPU STUDIO\logs

Notas sobre el uso del hardware (Sistema y NPU):
HK NPU STUDIO selecciona automáticamente el método de procesamiento adecuado (por ejemplo, aceleración Snapdragon NPU a través de QNN o procesamiento de CPU) para el modelo que está utilizando. Normalmente no necesita configurar nada manualmente en la pestaña «Sistema y NPU».

Las carpetas de salida y modelos pueden cambiarse en «Configuración». Compruebe allí la ruta guardada actualmente.

15. Cambiar y guardar el idioma
-------------------------------
1. Abra «Configuración».
2. Busque «Interfaz de usuario e idioma».
3. En «Idioma», elija Deutsch, English o Español.
4. Haga clic en «Guardar».
5. Los cambios de interfaz e idioma se aplican directamente después de guardar.

16. Errores frecuentes
-----------------------
- «El modelo no está instalado»: abra el Gestor de modelos e importe el paquete ZIP/SMP correspondiente.
- La acción de descarga aparece como «No disponible»: no hay una URL oficial configurada para este modelo. Use un paquete local obtenido legalmente.
- «width no es compatible»: active de nuevo el modelo correcto. Phoenix fija SD3.5 en 1024 × 1024 y SD1.5/SD2.1 en 512 × 512.
- El modelo NPU no inicia: compruebe que el paquete, el runtime QNN y los controladores correspondan al dispositivo.
- Memoria insuficiente: cierre otros programas grandes. No use una resolución superior a la permitida por el modelo.
- RealESRGAN falla: compruebe el modelo RealESRGAN local y el runtime QNN. La imagen original se conserva.
- ControlNet no influye: compruebe si la casilla de verificación en el menú emergente está activa, si se ha cargado una imagen de referencia válida y si el modelo activo es compatible con ControlNet.
- El idioma no cambia: asegúrese de hacer clic en «Guardar» en Configuración después de seleccionar el idioma.

17. Preguntas frecuentes
------------------------
¿Puedo crear imágenes sin conexión a Internet?
Sí. Los modelos instalados se ejecutan localmente. Puede necesitar Internet para obtener un modelo que falte.

¿Debo escribir los prompts en inglés?
No. Phoenix Boost reconoce alemán, inglés y español. Los modelos de imagen pueden responder de forma diferente según el idioma.

¿Por qué no puedo cambiar la resolución?
Algunos backends solo admiten un tamaño fijo. Phoenix oculta entonces la selección libre.

¿Por qué dos imágenes con semilla -1 son diferentes?
-1 solicita una semilla aleatoria para cada trabajo.

¿Se sobrescribe el original con el escalado 2x?
No. La imagen ampliada se guarda por separado.

¿Puedo activar varios modelos a la vez?
No. Un modelo queda seleccionado como modelo activo para el siguiente trabajo.

18. Aviso sobre el proyecto independiente de código abierto
------------------------------------------------------------
HK NPU STUDIO es un proyecto independiente de código abierto. No es un producto oficial de Qualcomm. Las marcas y nombres de modelos pertenecen a sus respectivos propietarios. Respete las licencias de todos los modelos utilizados y descargue paquetes únicamente de fuentes para las que tenga autorización.
