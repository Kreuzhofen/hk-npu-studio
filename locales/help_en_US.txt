HK NPU STUDIO – Step-by-Step Help

1. What is HK NPU STUDIO?
---------------------------------
HK NPU STUDIO creates images from text descriptions. Processing runs locally on your Windows PC. Depending on the model, the app uses the Snapdragon NPU or the CPU.

A “model” is the file that has learned how to create images. A model must be installed and activated before you can create an image.

2. Requirements
---------------
- A Windows 11 ARM64 PC with Qualcomm Snapdragon.
- Enough free storage for the selected model.
- For NPU models: a working Qualcomm QNN runtime and matching drivers.
- A completely installed model package.
- For local import: a matching ZIP or SMP file.

The app does not download every model automatically. If no official source is configured, you need an already downloaded local package.

3. First start
--------------
1. Start HK NPU STUDIO. On the first start, a background readiness check analyzes your system environment (Windows 11 ARM64, NPU drivers, Python).
2. Wait until the main view is loaded.
3. Open the "Model Manager" in the left navigation.
4. Search for the desired model (Stable Diffusion 1.5 QNN is recommended as a starting point).
5. Check the status: If the model is marked as "Not Installed", follow the instructions in Section 6.
6. Once a model is installed, select it and click "Set as active model".
7. Switch to "AI Generate" to create your first image.

4. Quick tour of the interface
-------------------------------
- “Home”: shows the general status.
- “AI Generate”: enter your prompt and start an image here.
- “Model Manager”: install and activate models here.
- “Gallery”: shows saved images.
- “Settings”: contains language and storage folders, among other options.

In “AI Generate” you will find:
- “YOUR PROMPT” and “EXCLUDE (NEGATIVE PROMPT)” for text input.
- “Presets & Templates” for saved settings.
- “Phoenix Boost” for local prompt suggestions.
- “Generation parameters” for resolution, steps, CFG, seed, and other values.
- “ControlNet/Canny” for guidance with a reference image.
- “History” for earlier prompts.
- “GENERATE IMAGE →” to start.

5. Which model should I choose?
--------------------------------
Stable Diffusion 1.5 (SD1.5)
- An easy starting point with a native resolution of 512 × 512.
- Phoenix offers QNN and optional QAI AppBuilder variants.

Stable Diffusion 2.1 (SD2.1)
- An alternative to SD1.5 with its own image characteristics.
- The current QNN/QAI packages use 512 × 512.

Stable Diffusion 3.5 Medium QAI AppBuilder
- The largest NPU model listed here.
- Phoenix uses a fixed resolution of 1024 × 1024.
- It requires a local package with four QAI contexts, two tokenizers, and additional files.

Stable Diffusion XL Base (SDXL)
- Runs through the CPU in the current Phoenix path.
- Use the resolution and defaults Phoenix displays for the installed package.

QNN and QAI in simple terms
- The NPU is the AI computing part of the Snapdragon processor.
- QNN is Qualcomm’s runtime for this NPU.
- QAI AppBuilder loads prepared model contexts. Phoenix runs this in a separate worker process.
- You do not need to configure these terms. Just select the matching installed model.

6. Step by step: Install a model
---------------------------------
1. Open “Model Manager” on the left.
2. Click the model you want.
3. Check the status:
   - “Not Installed”: the required model files are missing locally on your system.
   - “Installed”: the package was found and is ready.
   - “Active Model”: this model is currently selected for generations.
4. For a model marked “Not Installed”, click “Install”.
5. In the installation dialog, depending on the model, up to three options are available:
   - DIRECT / OFFICIAL_EXTERNAL: Download from a configured official website or source (Hugging Face / Qualcomm Link). Note: There is no fully automated direct download from the Qualcomm AI Hub; you will be guided to the respective official download page.
   - LOCAL_ONLY: Import a local package that you have already downloaded manually.
   - Cancel: Ends the installation process.
6. For local import (LOCAL_ONLY): Select the matching ZIP or SMP file in the Windows file dialog.
7. The installer checks and unpacks the package (staging), performs the static verification, and moves the files to your model directory.
8. After a successful import, select the model again and click “Set as active model”.
9. Click the “Create First Image” button to navigate directly to the generation page.

Note on Hugging Face: Entering a Hugging Face token in the settings is optional. A token is only required to access certain password-protected models on Hugging Face; there is no general registration or token requirement.

Phoenix checks the package ID, manifest, and files. Do not rename model contents yourself.

7. Step by step: Create your first image
-----------------------------------------
1. Activate an installed model in “Model Manager”.
2. Open “AI Generate” on the left.
3. Under “YOUR PROMPT”, enter for example:
   a professional photograph of a red sports car on a mountain road, daylight, sharp focus
4. Under “EXCLUDE”, enter for example:
   blurry, distorted, low quality
5. Open “Generation parameters”.
6. For your first attempt, keep the defaults shown for the model.
   - SD1.5/SD2.1: 512 × 512, usually 20 steps and CFG 7.5.
   - SD3.5 Medium QAI: 1024 × 1024, 8 steps and CFG 3.5.
   - SDXL: the currently displayed package values.
7. Use seed -1 for a random image, or for example 12345 for a repeatable starting value.
8. Close or apply the parameter dialog.
9. Click “GENERATE IMAGE →”.
10. Watch the status and progress. Do not close the app during generation.
11. After success, the status shows the measured total time.
12. The image appears in the preview and is saved in the output folder. You can also find it in “Gallery”.

Duration depends on the model, steps, upscaling, hardware, and other running programs.

8. Parameters in simple terms
------------------------------
- Steps: the number of denoising steps. More steps take more time. More is not automatically better.
- CFG Scale: how strongly the model follows the prompt. For many classic Stable Diffusion models, 6 to 8 is a useful range. For SD3.5, start with the displayed model default.
- Seed: the starting number for image calculation. The same seed and settings help reproduce a result. -1 selects a random seed.
- Sampler: the calculation method used to form the image.
- Scheduler: distributes denoising steps across the process.

If Sampler or Scheduler is disabled, it is fixed for that model or backend.

9. Presets
----------
A preset stores the prompt, negative prompt, and generation values, allowing them to be loaded quickly.

Rules when applying a preset:
- The active model is not changed when loading a preset (the selected model is preserved).
- An active ControlNet state and the loaded reference image remain preserved.
- Prompt, negative prompt, and compatible parameters are applied directly.
- Parameters not supported by the active model are automatically adjusted to the boundaries of the active model.
- The preset selection dialog can be opened repeatedly without errors.

Use an existing template:
1. In “AI Generate”, click “Presets & Templates”.
2. Select a template.
3. Click “Apply”.

In the same window, you can “Rename” or “Delete” templates. A new template can be created after a Phoenix Boost preview by selecting “Save as Template”.

10. Phoenix Boost
-----------------
Phoenix Boost is a purely optional AI assistant to optimize prompts.
- How it works: The function enhances your entered prompt and suggests matching parameters (steps, CFG) and exclusions. Execution runs locally and offline using Ollama and the Qwen model (no cloud required).
- Important: Phoenix Boost is NOT required for normal image generation. It is a formulation helper and NOT a speed boost that accelerates the actual image generation process.

Operation:
1. Enter a prompt first.
2. Click “Phoenix Boost”.
3. Compare the original and the suggestion.
4. Check the negative prompt, steps, CFG, and resolution.
5. Click “Apply” or “Cancel”.
6. Optionally select “Save as Template”.

11. RealESRGAN 2x – step by step
---------------------------------
RealESRGAN enlarges the completed image to twice its width and height. The original is preserved. The current plugin path uses the existing QNN backend.

1. Open “Generation parameters”.
2. Enable “Upscale 2× with RealESRGAN after generation”.
3. Apply the settings.
4. Click “GENERATE IMAGE →”.
5. Wait for normal generation first and then for upscaling.
6. The output folder contains the original and an additional file with “_2x” in its name.

If the option is off, the existing generation flow remains unchanged. The QNN runtime and RealESRGAN model must be available for upscaling.

12. ControlNet Canny – step by step
------------------------------------
ControlNet Canny copies edges from a reference image. This can guide the broad shape of the new image.

1. Open “Model Manager”.
2. Install “ControlNet Canny QNN” and set this exact model as the active model. It already contains the required SD1.5 base pipeline. Do not leave “Stable Diffusion 1.5 QNN” active instead; Phoenix uses only one active model at a time.
3. Open “AI Generate”.
4. Click “ControlNet/Canny” in the prompt toolbar. A separate popup opens; it is not a tab.
5. In the popup, also enable the “ControlNet Canny” checkbox. This enables Canny guidance for the job; it does not activate a second base model.
6. Click “Select Image” or drop an image into the reference area.
7. Check “Original Image” and “Canny Preview”.
8. If needed, adjust “Canny Low Threshold”, “Canny High Threshold”, and “Conditioning Strength”. Keep the defaults for your first test.
9. Close the popup. The image and values remain visible in the interface.
10. Enter your prompt and negative prompt.
11. Click “GENERATE IMAGE →”.

“Remove Image” removes the selected reference image from the current job. ControlNet Canny uses 512 × 512 in Phoenix.

Note: If the checkbox in the popup is active, the structure control is reliably applied to the generation job.

13. Gallery and History
-----------------------
- “Gallery” shows generated images from the output folder. Select an image to view it.
- “History” in “AI Generate” shows earlier prompts and their settings. Using the menu option “Clear history” / “Historie leeren”, the history can be completely cleared after confirming a security dialog. Important: The generated image files on your disk are NOT deleted by clearing the history.

Gallery and History are separate: Gallery manages physical image files. History stores your generation inputs.

14. Storage locations and System settings
-----------------------------------------
Development default paths:
- Images: C:\SnapdragonAI\output
- Models: C:\SnapdragonAI\models
- Settings and history: C:\SnapdragonAI\data
- Logs: C:\SnapdragonAI\logs

Installed-version default paths:
- Images: %LOCALAPPDATA%\HK NPU STUDIO\output
- Models: %LOCALAPPDATA%\HK NPU STUDIO\models
- Settings and history: %LOCALAPPDATA%\HK NPU STUDIO\data
- Logs: %LOCALAPPDATA%\HK NPU STUDIO\logs

Notes on hardware usage (System & NPU):
HK NPU STUDIO automatically selects the appropriate processing method (e.g. Snapdragon NPU acceleration via QNN or CPU processing) for the model you are using. In the settings under “System & NPU”, the user normally does not need to configure anything manually.

Output and model folders can be changed in “Settings”. Check the currently saved path there.

15. Change and save the language
--------------------------------
1. Open “Settings”.
2. Navigate to “UI & Language”.
3. Under “Language”, choose Deutsch, English, or Español.
4. Click “Save”.
5. UI and language changes are applied directly after saving.

16. Common errors
-----------------
- “Model is not installed”: open Model Manager and import the matching ZIP/SMP package.
- Download action is “Not available”: no official URL is configured for this model. Use a legally obtained local package.
- “width is not supported”: activate the correct model again. Phoenix sets SD3.5 to 1024 × 1024 and SD1.5/SD2.1 to 512 × 512.
- NPU model does not start: check that the package, QNN runtime, and drivers match the device.
- Not enough memory: close other large programs. Do not use a higher resolution than the model allows.
- RealESRGAN fails: check the local RealESRGAN model and QNN runtime. The original image remains preserved.
- ControlNet has no influence: check if the checkbox in the popup is active, a valid reference image has been loaded, and the active model supports ControlNet.
- Language remains unchanged: make sure you clicked “Save” in Settings after choosing your language.

17. FAQ
-------
Can I create images without internet access?
Yes. Installed models run locally. Internet may be needed to obtain a missing model.

Must I write prompts in English?
No. Phoenix Boost recognizes German, English, and Spanish. Image models may respond differently to different languages.

Why can I not change the resolution?
Some backends support only one fixed size. Phoenix then hides the free selection.

Why do two images with seed -1 differ?
-1 requests a random seed for every job.

Is the original overwritten by 2x upscaling?
No. The enlarged image is saved separately.

Can I activate several models at once?
No. One model is selected as the active model for the next job.
