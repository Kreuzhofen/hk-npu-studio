# Hero

Snapdragon AI Studio is an open-source AI development environment designed for
Windows on ARM devices powered by Qualcomm Snapdragon platforms.

The project focuses on running modern generative AI workloads with a clean,
desktop-oriented user experience while providing an extensible architecture for
future AI backends.

# Overview

Snapdragon AI Studio combines usability, modularity and performance into a
single desktop application for AI image generation and experimentation.

The Phoenix Engine separates UI, inference and backend logic, allowing new AI
providers to be integrated with minimal impact on the rest of the application.

# Installation

## Clone

```bash
git clone https://github.com/Kreuzhofen/snapdragon-ai-studio.git
cd snapdragon-ai-studio
```

## Launch

```bash
python gui_v2.py
```

# System Requirements

| Component | Requirement |
|-----------|-------------|
| OS | Windows 11 |
| Architecture | ARM64 |
| Python | 3.11 |
| RAM | 16 GB recommended |
| Storage | 5 GB+ |
